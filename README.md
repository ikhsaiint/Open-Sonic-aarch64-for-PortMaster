# Open-Sonic-aarch64-for-PortMaster
# Open Sonic for PortMaster  PortMaster package for Open Sonic, a free 2D platformer.  - Architecture: AArch64 - Launcher: `Open Sonic.sh` - Executable: `opensonic/opensonic.aarch64` - Controls: `opensonic/opensonic.ini` - Includes game assets and bundled libraries.  Hardware compatibility remains unverified.
